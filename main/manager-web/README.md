## xiaozhi

### Настройка проекта

При разработке используйте редактор кода. При импорте проекта выберите папку `manager-web` в качестве корневого каталога.

```bash
npm install
```

### Компиляция с горячей перезагрузкой для разработки

```bash
npm run serve
```


Сборка для продакшена (минификация)

```bash
npm run build
```
