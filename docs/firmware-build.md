# Компиляция прошивки для ESP32

## Шаг 1. Подготовьте ваш OTA-адрес

Если вы используете версию проекта 0.3.12, независимо от того, развёрнут ли простой сервер или полный модуль, OTA-адрес уже должен быть доступен.

Поскольку настройка OTA-адреса для простого сервера и полного модуля отличается, выберите подходящий вариант:

### Если вы используете простой сервер (Simple Server)

Откройте в браузере ваш OTA-адрес, например:

`http://192.168.1.25:8003/xiaozhi/ota/`

Если отображается **«OTA-интерфейс работает нормально, WebSocket-адрес для отправки устройству: ws://xxx:8000/xiaozhi/v1/»**, значит всё в порядке.

Запустите модуль `digital-human`, откройте `index.html` и проверьте, удаётся ли подключиться к WebSocket-адресу, выведенному на странице OTA.

Если страница недоступна, отредактируйте файл конфигурации `.config.yaml`, измените `server.websocket` на правильный адрес, перезапустите сервер и повторите тест, пока `index.html` не начнёт正常工作.

После успеха переходите к **Шагу 2**.

### Если вы используете полный модуль (Full Module)

Откройте в браузере ваш OTA-адрес, например:

`http://192.168.1.25:8002/xiaozhi/ota/`

Если отображается **«OTA-интерфейс работает нормально, количество WebSocket-кластеров: X»**, переходите к Шагу 2.

Если отображается **«OTA-интерфейс работает неправильно»**, вероятно, вы ещё не настроили WebSocket-адрес в _Панели управления_. Выполните следующие действия:

1.  Войдите в панель управления как суперпользователь.
2.  В верхнем меню нажмите **«Управление параметрами»**.
3.  В списке найдите параметр `server.websocket` и введите ваш WebSocket-адрес. Например:

`ws://192.168.1.25:8000/xiaozhi/v1/`

После настройки обновите страницу OTA-интерфейса и проверьте, стала ли она нормальной. Если нет — убедитесь, что WebSocket-сервер действительно запущен и адрес указан верно.

## Шаг 2. Настройка окружения

Сначала настройте окружение проекта по этому руководству:

[Установка ESP IDF 5.3.2 и компиляция Xiaozhi в Windows](https://icnynnzcwou8.feishu.cn/wiki/JEYDwTTALi5s2zkGlFGcDiRknXf)

## Шаг 3. Откройте конфигурационный файл

После настройки окружения загрузите исходный код проекта **xiaozhi-esp32**:

[Исходный код xiaozhi-esp32 на GitHub](https://github.com/78/xiaozhi-esp32)

После загрузки откройте файл `xiaozhi-esp32/main/Kconfig.projbuild`.

## Шаг 4. Измените OTA-адрес

Найдите строку `OTA_URL` с параметром `default`. По умолчанию там стоит:

`https://api.tenclass.net/xiaozhi/ota/`

Замените его на ваш собственный OTA-адрес. Например, если ваш адрес:

`http://192.168.1.25:8002/xiaozhi/ota/`

то после изменения должно быть так:

    config OTA_URL
        string "Default OTA URL"
        default "http://192.168.1.25:8002/xiaozhi/ota/"
        help
            The application will access this URL to check for new firmwares and server address.

_Обратите внимание: в оригинале дважды упоминается «Шаг 4» – мы сохранили нумерацию как в исходнике, но по смыслу это единый шаг._

## Шаг 5. Установите параметры компиляции

Выполните в терминале:

    # Перейдите в корневую директорию xiaozhi-esp32
    cd xiaozhi-esp32
    # Установите цель компиляции, например для ESP32-S3 (если у вас другая плата – укажите свою)
    idf.py set-target esp32s3
    # Запустите меню конфигурации
    idf.py menuconfig

В меню перейдите в раздел **Xiaozhi Assistant** и установите `BOARD_TYPE` в соответствии с вашей платой.

Сохраните изменения и выйдите из меню, вернувшись в терминал.

## Шаг 6. Компиляция прошивки

    idf.py build

## Шаг 7. Упаковка BIN-файла

    cd scripts
    python release.py

После выполнения команды в каталоге `build` появится файл `merged-binary.bin` – это итоговая прошивка, которую нужно загрузить на устройство.

**Примечание:** Если после второй команды появляется ошибка, связанная с «zip», проигнорируйте её, если файл `merged-binary.bin` был создан — это не влияет на результат.

## Шаг 8. Прошивка устройства

Подключите ESP32 к компьютеру, откройте браузер Chrome и перейдите по адресу:

`https://espressif.github.io/esp-launchpad/`

Ознакомьтесь с руководством: [Инструмент прошивки / Web-прошивка (без IDF)](https://ccnphfhqs21z.feishu.cn/wiki/Zpz4wXBtdimBrLk25WdcXzxcnNS).

Перейдите к разделу **«Способ 2: ESP-Launchpad — прошивка через браузер»**, начиная с пункта **«3. Прошивка / загрузка на плату»**, и следуйте инструкциям.

После успешной прошивки и подключения к сети активируйте устройство по голосовой команде и обратите внимание на вывод консоли сервера.
